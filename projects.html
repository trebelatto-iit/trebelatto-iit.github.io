HOW LIKELY IS "LIKELY"?

MATH563

Nov. 2026 — present

This dataset released by TidyTuesday contains survey data where respondents assigned a "probability" score to various words & phrases that describe likelihood. Examples of words include "likely", "probable", "certain", and "impossible".

For my MATH563 project, I am analyzing this dataset using R to explore how different people interpret the chances of something occurring depending on how we use language to convey its "likelihood".

PLEURAL EFFUSION DETECTION CONVOLUTIONAL NEURAL NETWORK

Personal Project

Oct. 2026 — present

Trained a DenseNet-121 CNN to detect pleural effusion in 180K+ chest radiographs from Stanford’s CheXpert dataset, achieving 0.876 validation AUROC with patient-level data splitting 65K patients. Evaluated model behavior beyond headline metrics using Grad-CAM attention analysis, subgroup performance breakdowns by view position and demographics, and bootstrapped confidence intervals. Next steps are to run Grad-CAM on high-confidence true and false positives, to check whether attention lands on costophrenic angles or on bedside hardware, run the subgroup breakdown on test (AP/PA, sex, age) and report any disparity, and check calibration and note whether the model is overconfident
