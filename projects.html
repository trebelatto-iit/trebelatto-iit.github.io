ONGOING PURSUITS

I've been experimenting with a Streamlit application to emulate the functionality of NotebookLM locally. So far, it uses Ollama running Mistral/Phi-3 locally with a vector database (Chroma) to retrieve relevant excerpts and ground responses in source material. Designed to run on my laptop without external API dependencies, with a simple chat interface that displays which document sections were used to answer each question. This way I simplify my AI workflow and avoid the dependencies created by the power of current LLMs.
